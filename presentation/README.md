# Project presentations

The repository keeps the two HTML slide decks under this top-level folder:

- [`ai-agent-harness/`](./ai-agent-harness/) — eight slides summarizing the AI agent harness architecture, workflow stages, controls, and draft implementation status.
- [`whole-project/`](./whole-project/) — ten slides covering the end-to-end CMDB, ADM, ITSM transformation: strategy, domains, data model, human workstreams, harness role, workflow, gates, roadmap, and outcomes.
- [`index.html`](./index.html) — browser-friendly landing page with ordered slide links.

Each slide is a standalone 1280×720 HTML document. Open the linked slide pages in a browser or host the repository with static-site hosting. The cover image is bundled locally under each deck's `assets/` directory; the cover pages use a relative image path so the repository copy is portable. The presentation decks were authored in the Slides workspace; these copies are the source HTML pages, not a replacement for the Slides resources.
