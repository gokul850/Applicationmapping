Mission and Non-negotiables

Objective

Transform the organization's existing registry, Azure resources, and on-premises inventory into an evidence-based, governed model in Device42.

Option B Strategy: Deploy stable logical application groups representing product responsibilities, moving progressively toward Option C ownership.

Non-Negotiable Principles

  • Policy Before Autonomy: Hard read-only boundaries outside the prompt. Prompt text is not a security control.
  • Evidence-Led ADM: One connected dependency graph. Links require traceable evidence, never inferred from shared infrastructure.
  • Human Authority: No production changes, merges, or deletions without explicit human approval.
  • Preserve Provenance: Original source IDs, aliases, and uncertainty must be visible in every proposal.
